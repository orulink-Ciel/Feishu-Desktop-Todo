# 值日制度与手工周排班

## 管理原则

值日由管理员每周手工安排，飞书多维表格是唯一数据源。桌面端只读取、展示今天和未来 7 天的安排，不推算轮值、不自动顺延，也不允许普通员工在桌面端改班。有人出差、请假或临时调换时，管理员直接修改当周对应日期即可。

Base 只保留一张「每周值日排班」表和一个「每周排班」视图。每周一条记录，管理员填周一起始日期、周一至周日的值日人员，并在「休息日」字段标记不值日的日期；日期展示列由公式根据周一日期生成。每日人员字段为空且未标记为休息时，桌面显示「待填写」，避免误把漏排当成休息。不再维护名单、轮值规则、节假日、请假或临时调整等其他表和字段。

## 每周填写方法

从桌面值日卡片打开「飞书排班表」，在「每周排班」视图中点击「添加记录」，每周只新增一行。选择当周周一作为「周起始日期」，然后在周一至周日的人员字段中选择值日人员，并在「休息日」字段勾选休息日；日期列会自动显示对应日期和星期。`排班备注`可记录整周说明。

有人请假、出差或互换班次时，直接修改当周对应日期的值日人员；不需要新增请假记录，也不会让后续排班自动变化。临时变化结束后，管理员按实际安排更新受影响的日期即可。

## 桌面端显示

桌面端从「每周值日排班」读取周起始日期、每日值日人员、休息日和备注，再展开为逐日安排。已勾选休息的日期显示「休息」；未选人员且未标记休息的日期显示「待填写」；没有覆盖该日期的周记录时显示「待排班」。点击刷新或定时同步会读取飞书当前内容；读取失败时显示错误或缓存状态，不将本地操作伪装成已同步。旧的逐日记录暂时保留，周记录优先用于重叠日期，避免迁移时丢失既有安排。
