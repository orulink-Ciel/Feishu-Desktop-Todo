## 仍需实际使用确认

1. 选择一条明确用于测试、已同步至任务中心的文档任务，从桌面完成后查看文档勾选是否同步变化。本次专用任务未绑定文档，不宣称已证明这条链路。
2. 在飞书客户端手动完成、重开或改日期，确认桌面显示及交互符合预期；目前已证明外部 API 变化可由原生轮询同步。
3. 点击任务和来源，确认当前机器飞书客户端/浏览器的实际跳转落点。
4. 在一台没有既有 CLI 配置的机器上完成首次配置与授权。首版复用 CLI OAuth，不等同于面向全公司的独立 OAuth 发布。

## 交付边界

默认个人使用、“我负责的”数据范围、包括此前所有逾期任务、只完成不编辑、本机固定和普通可置顶窗口均已写入需求文档。暂不提供开机启动、托盘、通知、离线写入、独立任务数据库或极序便签兼容。

本机所用 CLI 原生资源约 42.27 MiB，安装包压缩后约 11.3 MiB；不包含任何 CLI 配置或用户令牌。该版本为未签名的内部试用构建。
