# 飞书桌面待办图标

图标以“折页便签＋完成勾”表达桌面记录和完成任务，采用深墨蓝底、暖白纸页、青绿色勾。轮廓保持简单，透明留白适合 Windows 图标与 macOS Dock；图标颜色固定，应用六种主题仍可自由切换。

原始图为根目录 `app-icon.png`，通过内置 imagegen 生成。应用头部和浏览器图标使用 `public/app-icon.png`；Windows ICO、macOS ICNS 和各尺寸 PNG 放在 `src-tauri/icons`。Tauri 的 bundle.icon 明确引用原生图标，避免只替换界面标记。

替换根目录源图后生成所有尺寸：

```sh
npm run icons
```

## 生成提示词

Use case: logo-brand. Create one final production-ready desktop app icon for a lightweight Feishu personal task widget for Windows and macOS. A beautifully restrained premium minimal icon: one rounded square midnight ink-navy tile with softly rounded squircle corners; in the center, one ivory-white folded sticky-note sheet, drawn with clean precise geometry, and a confident deep teal completion checkmark integrated into the lower half of the sheet. The folded upper-right corner should subtly suggest an origami paper plane without resembling an existing brand logo. Quiet cool blue-teal shading, exceptionally subtle surface depth, crisp strong silhouette, generous internal breathing room. The symbol must remain clear at 24 and 32 pixels. Straight-on orthographic front view, absolutely no perspective tilt, no surrounding scene, no desk, no mockup. No text, no letters, no badge, no extra icon, no official Feishu logo, no busy gradients, no glossy plastic, no harsh drop shadow. Square 1024x1024 canvas. The single rounded-square icon should occupy about 90 percent of the canvas, centered. Transparent pixels outside the tile; the tile itself opaque. Design should feel calm, polished, timeless and crafted for a real productivity application.
